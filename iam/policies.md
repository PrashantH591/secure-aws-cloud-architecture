# IAM Policies

## Security Principle

This project follows the principle of least privilege.

Users and workloads should receive only the permissions required to perform their intended tasks.

## IAM Design

The project considers:

- IAM users
- IAM roles
- IAM policies
- Resource-level permissions
- Administrative access

## Security Practices

- Avoid unnecessary AdministratorAccess
- Use roles for AWS workloads
- Grant only required permissions
- Review permissions regularly
- Protect privileged accounts
- Enable MFA where appropriate

## Important

No real AWS credentials or access keys should ever be committed to this repository.
